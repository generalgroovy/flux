# Reference-style champion sprites v3

This directory reserves canonical paths for planned front-facing 256×256
transparent champion sprite candidates derived from the user-supplied FLUX
Champions visual baseline and canonical FLUX corrections. No v3 front-sprite
PNG is currently tracked.

The target is charming, expressive, equipment-led fantasy pixel art with clustered dark outlines, rich material ramps, readable elemental framing, and late Game Boy Color fantasy-adventure influence.

The catalog marks each absent file `planned_missing`; a path is not evidence that
an asset exists. Future files remain **front-view candidates**, not complete
directional animation atlases. The existing v2 atlases remain authoritative for
runtime animation until every direction and keyframe has been individually
redrawn, reviewed, and accepted. See
`content/visual/reference_style_front_catalog_v3.json`.
