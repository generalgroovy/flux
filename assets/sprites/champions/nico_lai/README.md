# Nico Lai visual candidate v1

Status: `integrated_candidate`, not final selectable content.

Nico Lai uses the canonical `size_1_tiny` Gnome presentation contract, the exact
32×32 cell and `(16, 28)` pivot, all eight directions and all 25 canonical
animation blocks. The original design uses a bald crown with pronounced side
hair, a compact teal engineering coat, brass device pack and Charge-readable
gauntlet.

Files:

- `nico_lai_atlas.png` — runtime candidate atlas;
- `nico_lai_overlay_debug_atlas.png` — skeleton envelope, pivot and baseline;
- `nico_lai_direction_preview.png` — nearest-neighbor direction review.

These pixels do not define collision, reach, statistics or ability outcomes.
