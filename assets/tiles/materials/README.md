# Foundation material tiles v1

`foundation_material_tiles_v1.png` contains eleven 16×16 presentation tiles in
canonical material order: empty, worldbone, stone, brick, wood, water, oil,
fire, steam, ice and rubble.

The atlas is driven by authoritative material IDs but remains presentation-only.
Screen pixels never define chemistry, collision, temperature, Charge, wetness,
elevation or structural state.
