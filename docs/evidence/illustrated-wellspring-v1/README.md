# Actual source-game captures

These are unedited Godot-rendered frames, not generated concept illustrations.

| File | Capture | Evidence |
|---|---|---|
| overview.png | 1920x1080, 50% zoom, frame 3 | Campus tiling, planting, six-area layout, buildings and HUD |
| camera-approach.png | 1280x720, 75% zoom, frame 8 | Elevated facades, cardinal floor geometry and roof fading near Oh Tipi |

Both use v13 champion pixels and illustrated campus v1, protocol 33, 120 Hz
simulation. Commands and additional movement/cast/grayscale captures are in
`.agent/memory.md`. Capture FPS is an offline movie cadence, not a claim that
every GPU sustains 120 rendered frames per second. Human acceptance is pending.
