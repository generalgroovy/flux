## Integration status

The two-row body-only foundation atlas is integrated as a validated candidate
for the current Windows runtime. It covers the six-cell directional/action
grammar used by the presentation adapter; simulation hitboxes and spell/effect
layers remain separate. Full roster promotion still requires one character at a
time with the same body contract, source provenance, native/zoom review and
visual acceptance evidence.

The older v2 race inventory remains a migration archive. Its five historical
size paths map `tiny→small`, `medium→middle`, and `huge→large`; they are not
selectable runtime values.
