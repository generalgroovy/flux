# Nexus-to-Conservatory visual slice v1

`nexus_to_conservatory_preview_v1.png` is the generated gameplay-scale review
image for the first visual slice. Its matching tile/RLE/worldbone presentation
data is stored in `content/maps/nexus_to_conservatory_visual_v1.json`.

Status: `presentation_only`.

The slice establishes a spacious Nexus plaza, attunement fountain, broad ordinary
causeway, Conservatory loop, rail route, wall-kick well, vault/slide devices and
an attunement spire. It does not replace authoritative collision, elevation,
material, reset, navigation or safety layers required by G2.
