# Reference-style champion sprites v3

This directory contains front-facing 256×256 transparent champion sprite candidates derived from the user-supplied FLUX Champions visual baseline and canonical Flux2 corrections.

The target is charming, expressive, equipment-led fantasy pixel art with clustered dark outlines, rich material ramps, readable elemental framing, and late Game Boy Color fantasy-adventure influence.

These files are integrated **front-view candidates**, not complete directional animation atlases. The existing atlases remain authoritative for runtime animation until every direction and keyframe has been individually redrawn, reviewed, and accepted. See `content/visual/reference_style_front_catalog_v3.json`.
