# FLUX 2 icon atlases v1

- `element_icons_v1.png`: eight 16×16 enabled-element icons in registry order.
- `foundation_ability_icons_v1.png`: six 32×32 icons for the current foundation abilities.
- `ui_state_icons_v1.png`: twelve 16×16 application-state icons.

Cell dimensions, ordering and paths are canonicalized in
`content/visual/visual_asset_registry_v1.json`. These compact atlases are a
production foundation; individual icon families still require contextual
color-vision, grayscale and final UI acceptance before release promotion.
