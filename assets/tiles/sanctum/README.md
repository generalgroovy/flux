# Sanctum modular tile kit v1

`sanctum_tiles_v1.png` is a 256×256 atlas of 16×16 virtual-pixel modules. Tile
IDs, regions and semantic tags are defined in
`content/visual/visual_asset_registry_v1.json`.

The first kit covers worldbone, plazas, paths, grass, moss, timber and
undercroft floors, water, cliffs, roofs, shore transitions, bridges, shrines,
vegetation and interaction devices. Presentation tags never replace authored
collision, worldbone, elevation, material or navigation data.
